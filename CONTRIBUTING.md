# Contributing

Thanks for helping improve Docxion.

Keep changes small and focused. This repository currently contains three parts: the Android `Docxion` library, the `office-viewer` TypeScript package, and the `Example` Android app.

Before opening a pull request, please:

1. Keep implementation changes limited to what is required.
2. Update documentation when public behavior changes.
3. Check the relevant build for the part you touched.
4. Avoid mixing unrelated refactors into the same change.

If you are changing the Android library, verify the `Docxion` module and the `Example` app. If you are changing the TypeScript viewer, verify the `office-viewer` build.
